\section{Tujuan Percobaan}
\begin{enumerate}[label=\alph*.]
  \item Mahasiswa mampu memahami prinsip kerja virtualisasi, perbedaan antara Host OS dan Guest OS, serta peran Hypervisor dalam manajemen sumber daya.
  \item Mahasiswa mampu melakukan instalasi dan konfigurasi awal Oracle VM VirtualBox pada komputer host.
  \item Mahasiswa mampu mengonfigurasi Virtual Machine (VM) dan menginstal sistem operasi Linux Server (Ubuntu) di dalamnya.
  \item Mahasiswa memahami konfigurasi jaringan pada VirtualBox untuk menghubungkan Host Computer dengan Virtual Machine.
\end{enumerate}

\section{Hasil dan Pembahasan}
\par Pada praktikum kali ini, saya melakukan instalasi Ubuntu Server pada Oracle VM VirtualBox. Proses instalasi berjalan lancar dengan beberapa langkah utama, yaitu:
\begin{enumerate}[label=\alph*.]
  \item Mengunduh dan menginstal Oracle VM VirtualBox pada komputer host (sudah terinstall di komputer saya).
  \item Mengunduh file ISO Ubuntu Server dari situs resmi Ubuntu untuk digunakan sebagai media instalasi.
  \item Membuat Virtual Machine baru dengan spesifikasi yang sesuai untuk Ubuntu Server.
  \item Mengonfigurasi pengaturan VM, termasuk alokasi RAM, ukuran hard disk, dan pengaturan jaringan.
  \item Memulai VM dan mengikuti proses instalasi Ubuntu Server, termasuk pemilihan bahasa, zona waktu, dan partisi disk.
  \item Melakukan konfigurasi jaringan pada VirtualBox untuk memastikan VM dapat terhubung dengan Host Computer dan jaringan lokal.
\end{enumerate}

\subsection{Mendownload file ISO Ubuntu Server}\
\par Karena komputer yang saya pakai sudah terinstall Oracle VM VirtualBox, langkah pertama yang saya lakukan adalah mengunduh file ISO Ubuntu Server. File ISO ini akan digunakan sebagai media instalasi untuk Virtual Machine yang akan saya buat di VirtualBox.
