\section{Tujuan Praktikum}
\begin{enumerate}
  \item Mahasiswa mampu memahami arsitektur Client-Server dengan memisahkan sisi Backend (API di Ubuntu Server) dan Frontend (Aplikasi Web di Komputer Host).
  \item Mahasiswa mampu melakukan deployment kode sumber REST API ke server Linux menggunakan fitur transfer file pada VS Code Remote SSH.
  \item Mahasiswa mampu melakukan impor database dari file SQL ke dalam server MySQL melalui terminal.
  \item Mahasiswa mampu melakukan pengujian fungsionalitas dari REST API (GET, POST, DELETE) menggunakan aplikasi Postman.
  \item Mahasiswa mampu mengintegrasikan aplikasi Frontend berbasis PHP di sisi klien agar dapat berkomunikasi dan bertukar data dengan REST API yang berada di server.
\end{enumerate}

\section{Hasil dan Pembahasan}
\par Pada pertemuan ini saya melakukan deployment REST API pada Ubuntu Server, mengimpor database MySQL, menguji endpoint menggunakan Postman, lalu mengintegrasikan aplikasi frontend berbasis PHP agar dapat berkomunikasi dengan REST API yang berjalan di VPS. Langkah-langkah yang saya lakukan meliputi:
\begin{enumerate}
  \item Menghubungkan ke server VPS menggunakan SSH melalui Visual Studio Code.
  \item Melakukan deployment dan transfer file backend REST API ke server menggunakan fitur Remote SSH.
  \item Mengimpor database dari file SQL ke dalam server MySQL melalui terminal.
  \item Menguji fungsionalitas REST API menggunakan aplikasi Postman.
  \item Mengintegrasikan aplikasi frontend berbasis PHP di komputer host dengan REST API pada VPS.
\end{enumerate}

\subsection{Deployment Backend REST API dan Impor Database}
\par Setelah berhasil terhubung ke VPS, saya membuka direktori web server dan memindahkan berkas backend REST API ke dalamnya. Pada Gambar \ref{fig:vscode-import-database-verifikasi} terlihat bahwa folder \texttt{sait\_api} telah berisi file penting seperti \texttt{config.php}, \texttt{mahasiswa\_api.php}, dan \texttt{mahasiswa.sql}. Dari terminal yang sama, saya kemudian mengimpor file SQL ke database MySQL menggunakan perintah pada Kode \ref{lst:mysql-import-saitdb}.
\par Pada perintah tersebut, saya menggunakan perintah \texttt{mysql} dengan opsi \texttt{-u root -p} untuk masuk sebagai user root, lalu menentukan nama database \texttt{sait\_db}, yang sudah saya buat di pertemuan sebelumnya, dan mengarahkan input dari file SQL yang berada di direktori backend REST API. Setelah menjalankan perintah tersebut, saya memasukkan password MySQL untuk user root agar proses impor dapat berjalan dengan sukses.

\begin{lstlisting}[language=bash, caption={Perintah impor file SQL ke database MySQL}, label={lst:mysql-import-saitdb}]
sudo mysql -u root -p sait_db < /var/www/html/sait_api/mahasiswa.sql
\end{lstlisting}

\begin{figure}[H]
  \centering
  \includegraphics[width=0.95\textwidth]{resource/vscode-import-database-verifikasi.png}
  \caption{Tampilan file backend REST API di VPS, proses impor database, dan verifikasi data pada MySQL}
  \label{fig:vscode-import-database-verifikasi}
\end{figure}

\par Setelah database berhasil diimpor, saya melakukan verifikasi langsung dari MySQL Shell dengan memilih database \texttt{sait\_db} dengan perintah use (nama database) dan seterusnya untuk menampilkan isi tabel \texttt{mahasiswa}, mengecek pengguna aktif, lalu memberikan hak akses kepada user lokal agar aplikasi PHP dapat mengakses database tersebut. Rangkaian perintah verifikasi yang digunakan ditunjukkan pada Kode \ref{lst:mysql-verifikasi-saitdb}.

\begin{lstlisting}[language=SQL, caption={Verifikasi isi database dan pemberian hak akses MySQL}, label={lst:mysql-verifikasi-saitdb}]
USE sait_db;
SELECT * FROM mahasiswa;
SELECT CURRENT_USER();
GRANT ALL PRIVILEGES ON sait_db.* TO 'fauzan'@'localhost';
FLUSH PRIVILEGES;
\end{lstlisting}

\par Berdasarkan Gambar \ref{fig:vscode-import-database-verifikasi}, data awal pada tabel \texttt{mahasiswa} berhasil terbaca dengan empat record, yaitu Andi, Dwi, David, dan Paul. Mohon maaf banyak kesalahan ketik yang saya lakukan karena kurang tanda ";" sehingga ketika di-enter bukan berarti perintah di submit tapi malah membuat baris baru. 

\subsection{Pengujian Fungsionalitas REST API dengan Postman}

\begin{lstlisting}[language=bash, caption={Endpoint REST API yang diuji dengan Postman}, label={lst:endpoint-postman-saitdb}]
GET    http://10.33.35.96/sait_api/mahasiswa_api.php
POST   http://10.33.35.96/sait_api/mahasiswa_api.php
POST   http://10.33.35.96/sait_api/mahasiswa_api.php?id_mhs=5
DELETE http://10.33.35.96/sait_api/mahasiswa_api.php?id_mhs=5

\par Berdasarkan percobaan yang telah saya lakukan, saya berhasil melakukan koneksi ke VPS melalui Visual Studio Code Remote-SSH, melakukan deployment backend REST API ke Ubuntu Server, mengimpor database MySQL, serta memverifikasi bahwa data dapat diakses dengan benar. Pengujian menggunakan Postman juga menunjukkan bahwa endpoint REST API berhasil menjalankan operasi \texttt{GET}, \texttt{POST}, \texttt{update}, dan \texttt{DELETE} sesuai dengan kebutuhan.

\par Selain itu, aplikasi frontend berbasis PHP juga berhasil diintegrasikan dengan REST API pada VPS dengan menggunakan endpoint yang sama seperti pada pengujian Postman. Hal ini dibuktikan melalui kemampuan frontend untuk menampilkan data, menambah data, mengubah data, dan menghapus data mahasiswa secara langsung melalui antarmuka web.
