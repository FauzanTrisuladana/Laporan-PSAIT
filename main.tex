\section{Tujuan Praktikum}
\begin{enumerate}
  \item Mahasiswa mampu melakukan konfigurasi akses jarak jauh (remote access) ke server Linux menggunakan protokol SSH pada Visual Studio Code
  \item Mahasiswa mampu membangun infrastruktur web server dengan melakukan instalasi paket Apache, PHP, dan MySQL (LAMP Stack) pada sistem operasi Ubuntu Server.
  \item Mahasiswa mampu memahami dan menerapkan manajemen hak akses (file permissions) pada direktori server untuk keperluan pengembangan web.
  \item Mahasiswa mampu melakukan manajemen database dasar melalui CLI (Command Line Interface), termasuk membuat database dan user baru
  \item Mahasiswa mampu membuat skrip PHP sederhana untuk memverifikasi konektivitas antara Web Server dan Database Server.
\end{enumerate}

\section{Hasil dan Pembahasan}
Praktikum kali ini saya mengikuti langkah-langkah sebagai berikut:
\begin{enumerate}
  \item Instalasi Ekstensi Remote SSH di Visual Studio Code

  \item Persiapan Database 
  \item Buka folder server di VS Code

\subsection{Instalasi Ekstensi Remote SSH di Visual Studio Code}
\par Pada bagian ini saya membuka Visual Studio Code, lalu mengakses menu Extensions di bagian sidebar atau (Ctrl+Shift+X) dan mencari ekstensi "Remote - SSH" \ref{fig:remote-ssh-extension} yang dikembangkan oleh Microsoft. Setelah menemukan ekstensi tersebut, saya mengklik tombol "Install" untuk memasangnya di Visual Studio Code. Tunggu proses instalasi dan setelah selesai, ekstensi siap digunakan untuk menghubungkan ke server VPS melalui protokol SSH.

\subsection{Persiapan Database}
\par Setelah memastikan MySQL Server sudah terinstal dan dapat diakses, saya melakukan persiapan database untuk pengujian koneksi antara Apache (PHP) dan MySQL. Saya masuk ke MySQL Shell menggunakan perintah pada Kode \ref{lst:mysql-shell}, lalu membuat database baru seperti pada Kode \ref{lst:create-database}. Setelah itu saya membuat user baru (Kode \ref{lst:create-user}), memberikan hak akses pada database tersebut (Kode \ref{lst:grant-privileges}), kemudian melakukan \textit{reload} hak akses (Kode \ref{lst:flush-privileges}). Rangkaian proses persiapan database dapat dilihat pada Gambar \ref{fig:persiapan-database}.

\begin{lstlisting}[language=SQL, caption={Membuat database baru}, label={lst:create-database}]
CREATE DATABASE fauzan;
\end{lstlisting}

\begin{lstlisting}[language=SQL, caption={Membuat user database}, label={lst:create-user}]
CREATE USER 'fauzan'@'localhost' IDENTIFIED BY 'fauzan123';
\end{lstlisting}

\begin{lstlisting}[language=SQL, caption={Memberikan hak akses user ke database}, label={lst:grant-privileges}]
GRANT ALL PRIVILEGES ON fauzan.* TO 'fauzan'@'localhost';
\end{lstlisting}

\begin{lstlisting}[language=SQL, caption={Menerapkan perubahan hak akses}, label={lst:flush-privileges}]

\end{lstlisting}

\subsection{Buka folder server di VS Code}

\par Setelah konfigurasi web server dan database selesai, langkah berikutnya adalah membuka folder web server di Visual Studio Code agar pembuatan file PHP menjadi lebih mudah. Secara default, direktori \texttt{/var/www/html} dimiliki oleh user \texttt{root} dan group \texttt{www-data}, sehingga user biasa tidak bisa menulis file tanpa \texttt{sudo}. Untuk mengatasi hal tersebut, saya menambahkan user saat ini ke group \texttt{www-data}, lalu mengatur kepemilikan dan permission direktori \texttt{/var/www/html} seperti pada Kode \ref{lst:www-data-permission}. Proses eksekusi perintah-perintah tersebut dapat dilihat pada Gambar \ref{fig:www-data-permission}.

\begin{lstlisting}[language=bash, caption={Konfigurasi group dan permission direktori /var/www/html}, label={lst:www-data-permission}]
sudo usermod -aG www-data $USER
sudo chown -R $USER:www-data /var/www/html
sudo chmod -R 775 /var/www/html
\end{lstlisting}

\begin{figure}[H]
  \centering
  \includegraphics[width=0.8\textwidth]{resource/www-data-permission.png}
  \caption{Proses konfigurasi group www-data dan permission direktori /var/www/html}
  \label{fig:www-data-permission}
\end{figure}

\par Untuk memastikan perubahan group sudah diterapkan, saya menjalankan perintah \texttt{id} seperti pada Kode \ref{lst:check-id}. Jika pada output terdapat group \texttt{www-data}, berarti konfigurasi berhasil. Tampilan hasil pengecekan tersebut dapat dilihat pada Gambar \ref{fig:check-id}. Apabila group \texttt{www-data} belum muncul, maka saya melakukan \textit{re-login} SSH atau menjalankan \texttt{sudo reboot} agar sesi user memuat ulang group.

\begin{lstlisting}[language=bash, caption={Memeriksa group user dengan perintah id}, label={lst:check-id}]
id
\end{lstlisting}

\begin{figure}[H]

\subsection{Uji Coba Koneksi dengan Skrip PHP}

\par Setelah folder \texttt{/var/www/html} berhasil dibuka pada VS Code (Gambar \ref{fig:open-folder-html}), saya membuat sebuah file PHP untuk menguji apakah web server dapat terhubung ke database MySQL yang telah disiapkan pada subbab sebelumnya. File tersebut saya beri nama \texttt{tes\_koneksi.php} dan saya isi dengan skrip koneksi MySQLi seperti pada Kode \ref{lst:tes-koneksi-php}. Pada skrip ini saya menggunakan database \texttt{fauzan} serta user \texttt{fauzan} yang telah diberi hak akses melalui perintah pada Kode \ref{lst:grant-privileges}.

\begin{lstlisting}[language=PHP, caption={Skrip PHP untuk menguji koneksi ke MySQL}, label={lst:tes-koneksi-php}]
<?php
$koneksi = mysqli_connect("localhost", "fauzan", "fauzan123", "fauzan");

if ($koneksi) {
    echo "<h1>Sukses lee!!! Web server terhubung ke database</h1>";
} else {
    echo "Gagal bolo: " . mysqli_connect_error();
}
?>
\end{lstlisting}

\par Setelah file berhasil disimpan, saya mengaksesnya melalui browser dengan URL \texttt{http://<IP-VPS>/tes\_koneksi.php}. Jika koneksi berhasil, maka halaman akan menampilkan pesan sukses seperti pada Gambar \ref{fig:tes-koneksi-php}.
